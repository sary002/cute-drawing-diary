叶簇与穗草已保存自然笔触修订版，旧图保留；叶形、空隙与暗部不再简化成规则圆团或排队色点。各课写明可省略的枝叶、木纹与碎石，不要求复制AI图所有细节。

纸笔使用现有16.5厘米方本与36色油性马克笔。配色依据实涂照片的相对色系，同纸试色优先，非精确色度验证。浅部提前留纸白，先浅后深；针管笔未知兼容时干后局部勾线，不依赖浅盖深。详细色号区域和步骤见唯一正文。
