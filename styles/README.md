# 绘画风格库

[返回首页](../README.md) · [全部教案](../lessons/README.md)

按画面特征保存可复用的风格档案。风格编号与作品编号分别管理，同一风格可画不同主题；新风格追加，不覆盖旧档案。

| 风格编号 | 名称与展示 | 关键词 | 当前用途 |
| --- | --- | --- | --- |
| S001 | [童趣色块手绘](001-playful-color-block.md) | 浓郁色块、自然笔触、呆萌表情、小情节 | 默认风格，含角色与几何风景两个方向 |

## 如何使用和补充

- “用S001风格，画一幅全新题材”：沿用视觉特点，重新设计角色、动作和构图。
- “今天换成另一种风格”：只切换本次，不自动覆盖默认风格。
- “把这种新风格加入风格库”：参考新图片或描述，追加S002、S003等档案，保留已有风格；默认风格仅在明确要求时切换。

每个档案包含展示图、色彩与线条规则、构图、适用题材、避免项、生成提示和关联教程。展示注明AI示意或真实手绘；原始照片默认私下保存，公开实拍需明确授权。
