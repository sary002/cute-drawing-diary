# 每天画点可爱的

每天约20分钟，用36色马克笔画一幅简单可爱的小画，同时学一个基础点。每一练都是一篇完整教案，在GitHub打开即可跟画。

**[开始每日一练 → 全部教案](lessons/README.md)** · **[第006练：接住一颗星星](lessons/beginner/006-catch-a-star.md)**

## 每日一练

### 入门版练习

- [入门指南：工具、试笔与练习方法](lessons/beginner/README.md)
- [001｜圆滚滚小鸡](lessons/beginner/001-chick.md)：基本形概括，使用37、24、9号。
- [002｜湖边小山丘](lessons/beginner/002-lakeside-hills.md)：前后遮挡，使用37、44、52、67号，约25分钟。

- [003｜窗边发呆的青蛙](lessons/beginner/003-sleepy-frog.md)：眼皮和瞳孔的位置表现情绪，约30分钟。
- [004｜猫咪送一朵花](lessons/beginner/004-cat-flower.md)：用视线和位置建立两个角色的互动，约30分钟。
- [005｜月夜蓝色山](lessons/beginner/005-moon-mountains.md)：用相邻的明暗色面表现山的体积，约25分钟。
- [006｜接住一颗星星](lessons/beginner/006-catch-a-star.md)：用大小和斜向安排突出画面焦点，约30分钟。

完整教案按阶段收录在[每日一练总目录](lessons/README.md)，新内容准备好后持续更新。
