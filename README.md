## 28幅之后怎么继续新增

**28幅全部画完后，直接说“用S001继续新增3幅”，就从S001-029、S001-030、S001-031接着编。** 仍属S001风格，默认继续D4自主创作；没有默认D5，也不用重新从D1开始。28幅是主线规划，不是作品数量上限，新内容追加保存。

每个风格独立连续编号：S001-001～S001-028为当前28幅；后续029、030……一直递增。阶段单独标注，回到D2加练也接着编号，不重新从001开始。S002若正式收录，有自己独立的001起点。新增时查询[编号登记表](config/material-sequences.json)取下一个号，不需要手动记住。改色或修正同一幅仍用原编号，以v2、v3区分版本；新题材才取新号，废弃号码不复用。

想指定阶段、素材用途或教学方式时，可用下面的说法：

| 想新增什么 | 归到哪里 | 可以直接这样说 |
| --- | --- | --- |
| 更多成品参考图 | 所选风格、所选等级的扩展成品素材 | “用S001，D2新增3幅成品素材，练表情，先只生成成品图。” |
| 能直接跟画的加练 | 所选风格、所选等级的扩展教案 | “用S001，D3新增2幅完整加练教案，画小商店，附详细步骤图和36色色号。” |
| 一项技法的小练习 | 对应等级的技法辅助素材 | “用S001，D2加一组曲线和遮挡小练习，不用完整成品。” |
| 自己设计题材或系列 | 所选风格D4的扩展创作任务；其他等级也可选自主教学方式 | “用S001，D4新增一个3幅的小系列，主题是旅行，先给任务和检查点。” |
| 依据新参考设计原创画面 | 先归所选风格与等级，再确定成品素材或教案用途 | “参考这张图的视觉特点，用S001设计一幅D3原创成品素材，主体和构图重新设计。” |
| 与已有风格明显不同的视觉方式 | 新风格候选，分析和预览后再确认收录 | “帮我分析这组新风格，先出原创候选，不修改已有风格。” |

记不住完整说法时，用这一句就够：

> 用S001继续新增3幅，主题是旅行，换一组配色。

数量、主题、配色都可以省略；缺省数量为1。“只加素材”先做成品预览，“完整加练教案”再准备相应步骤和正文。尚在学习主线时沿用该风格实际阶段；实际完成D4主线后，默认D4续创。当前28幅生成预览不等于实际画完，不据此自动改进度。

新增独立画面用S001-029这类素材编号，归入所选风格与阶段的续编素材；初始28幅主线保留。完整加练实际画完后计入对应阶段的练习与复盘；附属步骤、色卡和技法辅助页沿用所属素材号，不另算一幅完成作品。现有教案内部编号保留，选素材时以风格素材编号为准。细则见[通用学习规则](docs/learning-system.md)。

## 后续配色与结构检查

本项目有36色可选；每幅控制适合等级的色数，整组轮换主色、背景和冷暖。28课的成品、教学图、图内标注和正文已按实涂色卡相对色相修订，见[逐课修订记录](docs/color-repair-2026-11-01.md)与[当前色号统计](styles/previews/S001-2026-11-01/palette-report-v6.json)。当前方案安排35种色号，132不强行使用；安排次数不代表实际耗墨量或已经手绘用齐。旧图保留为历史版本。

后续选色同时看出现次数和使用面积，优先轮换最近承担大片背景的色号，也可留纸白或缩小背景范围；不能只换一个小配件就称为用色均衡。用墨量还受画幅、叠涂次数与笔的剩余墨量影响，次数统计不能当成实际耗墨测量。收到缺色或快用完的反馈后，再据此调整。

可以指定“换一组配色”“这次不用亮粉背景”或具体已有色号；不必为了使用36色在一幅里堆满颜色。色号以[工具档案](config/tools/touchmark-student-36-v2.json)为准，颜色表现以实物试色为准，132仍不当不透明白笔。

简化色块仍要让物体结构清楚。伞的弧面、口袋或容器的开口、桌面边缘等，应通过必要的透视、厚度、遮挡和少量明暗分面表达；不以扁平风格为由忽略结构。
