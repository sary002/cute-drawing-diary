# 每天画点可爱的

每天约20～30分钟，用36色马克笔画一幅简单可爱的小画，同时学一个基础点。每一练都是一篇完整教案，在GitHub打开即可跟画。

**[开始每日一练 → 全部教案](lessons/README.md)** · **[第012练：鲸鱼的晚安灯](lessons/beginner/012-whale-lantern.md)**

## 每日一练

### 入门版练习

- [入门指南：工具、试笔与练习方法](lessons/beginner/README.md)
- [001｜圆滚滚小鸡](lessons/beginner/001-chick.md)：基本形概括：用圆胖轮廓和小三角形搭出小鸡。
- [002｜湖边小山丘](lessons/beginner/002-lakeside-hills.md)：前后遮挡：树挡住山，湖岸挡住水。
- [003｜打哈欠的邮筒](lessons/beginner/003-yawning-mailbox.md)：用圆口与低眼皮表现打哈欠。
- [004｜鳄梨和果核玩跷跷板](lessons/beginner/004-avocado-seesaw.md)：用斜线和高低位置表现跷跷板动作。
- [005｜粉色天空下的条纹灯塔](lessons/beginner/005-striped-lighthouse.md)：用大块形状安排前中后层次。
- [006｜接住一颗星星](lessons/beginner/006-catch-a-star.md)：用大小和斜向安排突出画面焦点。
- [007｜偷吃月亮](lessons/beginner/007-moon-snack.md)：用夸张的大小对比突出道具。
- [008｜雨天的蜗牛](lessons/beginner/008-snail-leaf.md)：用一大一小的形状突出遮雨关系。
- [009｜云朵晾衣日](lessons/beginner/009-cloud-laundry.md)：用重复形状和疏密节奏安排画面。
- [010｜企鹅的热可可](lessons/beginner/010-penguin-cocoa.md)：用遮挡表现抱住杯子的动作。
- [011｜举着花盆的机器人](lessons/beginner/011-robot-flowerpot.md)：用视线和抬手方向引导注意力。
- [012｜鲸鱼的晚安灯](lessons/beginner/012-whale-lantern.md)：用大曲线连接画面中的两个焦点。

完整教案按阶段收录在[每日一练总目录](lessons/README.md)，新内容准备好后持续更新。
