# 每天画点可爱的

每天约20分钟，用36色马克笔画一幅简单可爱的小画，同时学一个基础点。每一练都是一篇完整教案，在GitHub打开即可跟画。

**[开始每日一练 → 全部教案](lessons/README.md)** · **[直接画第001练：圆滚滚小鸡](lessons/beginner/001-chick.md)**

[入门工具](lessons/beginner/README.md) · [学习方法](docs/workflow.md) · [参考资料](docs/learning-references.md) · [公开内容规则](docs/public-repository.md)

## 每日一练

### 入门版练习

从基本形、清楚轮廓和少色平涂开始，每幅约20分钟。

- **[入门指南：工具、用法与课程目录](lessons/beginner/README.md)**
- **[001｜圆滚滚小鸡](lessons/beginner/001-chick.md)**：基本形概括，使用37、24、9号。

目前有1篇完整教案。后续选题准备好后会更新[每日一练总目录](lessons/README.md)；进阶版将在有完整教案时增加分类，36色仍可继续使用。

## 基础与工具

- [本阶段工具与试笔方法](lessons/beginner/README.md)：16.5×16.5厘米马克笔纸、铅笔、36色马克笔、各规格针管笔与粗勾线笔。
- [每天怎么学](docs/workflow.md)：3分钟基础小练习＋15分钟画小作品＋2分钟检查，可灵活调整。
- [课程与参考资料](docs/learning-references.md)：简笔画基础课程、建议查阅章节与画本使用方法。

画的时候专心画，照片、实际用时和感受都可省略。可以重复练同一幅，或分两次完成；想留档时再集中拍成品，想分享时再整理。
