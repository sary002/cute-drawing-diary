# 多风格独立学习规则

[首页](../README.md) · [风格库](../styles/README.md) · [全部教案](../lessons/README.md)

## 先选风格，再沿共同阶梯学习

风格规定画面如何表达；阶段规定要掌握的能力；教学方式规定提供多少帮助。这三个维度分别管理。S001与以后新增的每种风格各自独立，不存在必须先完成S001才能学习其他风格的关系，也不把某一种风格当成另一种的进阶版。

每种风格都沿同一顺序学习：D1基础大形 → D2专项控制 → D3综合组织 → D4自主创作。共同的是能力目标、评估方式与教学质量，具体题材、线条、配色和技法由各风格决定。任何一级都要保留该风格的核心特点；扁平风格不必为了升级加入写实体积，风景也不必先练拟人角色。

首次学习时先选风格。已有明确选择则沿用；未指定时可展示风格库并说明当前默认，不必重复询问。选定后读取该风格自己的阶段、未完成作品和复盘记录。临时选择不改变默认风格。

## 所有风格共用的四级阶梯

| 等级与配置ID | 共同目标 | 教学内容边界 | 参考步骤与时间 |
| --- | --- | --- | --- |
| D1 基础大形 `beginner` | 能概括主要形状、位置和色块，处理简单遮挡与留白 | 少量大形，通常2～5色，每幅一个主要新知识点 | 常见4～6步，整幅约20～40分钟 |
| D2 专项控制 `intermediate` | 稳定控制一项适合该风格的技法，并迁移到不同题材 | 如线条粗细、植物笔触、表情变化、明暗分组或配色；不要求每种风格练同一种技法 | 常见6～9步，整幅约30～60分钟 |
| D3 综合组织 `scene` | 协调已学技能，安排主次、层次与疏密 | 可以是角色互动、物体组合或环境小景；整合旧技能，仍有一个当次主要重点 | 常见8～12步，整幅约45～90分钟，可分次 |
| D4 自主创作 `independent` | 自主决定构图、配色、取舍与操作顺序，形成系列 | 从主题、观察或自有素材出发；逐步减少成品依赖 | 按实际需要拆解，不设步骤上限，可分多次完成 |

时间与步骤都是教学估计，不作为晋级条件。颜色上限采用阶段配置的默认约束；若某种风格确需调整，先说明理由再更新配置，不通过堆颜色或纹理制造难度。步骤更多不必然更难，自主决定更多也可能是进阶。

## 每种风格的主线课程规模

每个阶段安排7幅主线作品，每种风格共28幅：D1为7幅基础大形，D2为7幅专项控制，D3为7幅综合组织，D4为7幅自主创作。这里是课程规划数量，不代表所有未来课程已经备好，也不是必须画满才能晋级的门槛。

每阶段的7幅按能力递进安排：第1～2幅建立本阶段技能，第3～4幅换题迁移，第5～6幅巩固与组合，第7幅用于阶段回看。D1以大形和色块为主，D2围绕一项技法在不同题材中练习，D3综合已有技能，D4以自主设计和主题系列为主；具体选题与操作由各风格决定。

需要巩固时，每轮另加2～3幅针对性练习，不计入28幅主线规模；重复练习同样可以用于能力评估。D4完成7幅后可继续原创系列，没有默认第五级。每阶段已具备能力时可以根据实际评估提前进阶，不能仅凭张数跳级。

已有教案超过7幅时保留为选题池，选择适合的7幅组织主线，其余作为替换或巩固题，不删除既有教程，也不要求全画完。新增风格逐阶段备课，尚未完成的题目继续标规划。

S001采用[28幅主线预览编排](../styles/previews/S001-2026-11-01/README.md)：原第02幅替换后，当前D1复用6幅并新增1幅，D2复用5幅并新增2幅，D3和D4各新增7幅，共复用11幅、新生成17幅。课程预览顺序与旧作品编号分开，当前28课均已备齐；D2复用图另加专项试练、检查与换题迁移，原D1阶段快照保留，旧链接重定向唯一的D2正文。D3每课8环节与递进图，D4每课10环节及四格构图与局部结构提示；实际手绘进度不变。

## 主线以外的扩展素材与加练

28幅主线是结构化起点，不限制长期新增数量。相同视觉风格继续使用原style_id；按训练目标归到D1～D4，增加画面不等于新风格，也不自动晋级。跨等级需求可以明确指定，但不改写当前学习阶段。

新增时分别识别用途：finished_reference为成品素材，practice_lesson为完整加练教案，technique_drill为技法辅助，creative_project为自主创作任务。题材、配色或构图变化一般仍属原风格；视觉表达明显改变时才分析为新风格候选。生成前确认该风格的等级、数量、用途、主要目标、教学方式及配色；信息已明确则直接执行。缺省阶段沿用所选风格独立进度，缺省数量为1；“素材”先按成品预览准备，“完整加练”按所选教学方式补图和正文。

素材编号采用“风格编号-至少三位连续序号”，例如S001-001～S001-028，下一幅为S001-029。每种风格跨D1～D4共用一条序列，换阶段不重置；新风格独立从001起。config/material-sequences.json是已分配最大号的登记表，课程预览manifest的material_id对应具体画面。新增前同时检查登记表、预览清单和已有materials目录，取已分配最大号加1，写入素材档案并推进登记表；取消或废弃已分配号不复用。同一画面的换色、修形、步骤图和教案沿用素材号并增加版本，不另取号。独立新画面或新任务才分配下一号，附属技法页和色卡不占新号。

28幅之后的新素材可追加到materials/风格编号/等级/素材编号/，记录material_id、style_id、stage、kind、goal、course_role=supplemental、配色、来源与提示词。已有预览不移动；当前28幅已补上连续素材号映射。素材编号面向选题与续编，与旧教案内部作品编号分别管理。

完整加练正文与entry.json继续遵循原教案路径和全库唯一作品编号，可追加course_role=supplemental及material_id关联扩展素材；不能直接拿预览顺序当作品编号。新增材料不改变主线28幅，不替换旧画，明确要求调整主线时才重编。只有实际完成的加练作品才计入对应风格阶段的练习总数与能力复盘；纯素材、辅助页和未实际完成的任务不计入。每轮2～3幅是针对问题的建议，不是扩展内容的总上限。

D4主线实际画完后可持续开展新主题和系列，无默认D5；“用S001继续新增3幅”默认D4、取下三个未分配素材号。当前只有001～028时即为029～031。有需要也可指定回D1～D3补专项，仍接着编号且不清空进度。主线尚未完成时，未指定等级则恢复该风格实际阶段。生成预览不等于实际画完；只有实际练习与复盘才能推进阶段。可复制的请求示例见[首页新增指南](../README.md)。

## 独立进度与晋级

- 正式风格登记在config/styles.json。config/learning-progress.json以style_id分别记录current_stage、teaching_mode和reviews；实际完成数从对应风格的entry.json计算，避免重复维护。
- 新风格默认从D1开始；已有可迁移能力时可安排短诊断，根据实际练习或明确能力信息决定起点，不自动继承其他风格的阶段。
- 切换风格时恢复该风格的记录；选题、恢复未完成作品和完成计数都按所选风格过滤，其他风格的待完成作品不构成阻塞。
- 每个风格、每个阶段首次完成7幅后提示复盘。7幅是检查点，不是固定毕业数；AI候选图、待手绘教案及未实际完成的作品不计入。
- 按config/stages.json的能力标准结合成品或文字反馈复盘，无需强制照片、逐幅表格或过程拍摄。能稳定做到核心目标时进入下一级；尚需练习时补约2～3幅针对性练习，再复盘。
- 到达张数时只提示，不按数量自动晋级。复盘可记录advance、practice或stay及简短绘画依据；不能仅以“张数够了”作为依据。D4继续做自主项目和阶段回看，没有默认第五级。
- 旧作品、工具快照、阶段快照与完成记录不追溯重写。历史记录缺少style_id时显示未分类，不按当前默认风格猜测，也不计入任何风格的晋级数量；需要归类时再单独确认。已有S001教案仍可照原六步图练习。

## 教学方式与步骤

三种教学方式适用于所有风格、所有等级；阶段与帮助程度可以单独调整。

| 方式 | 配置值 | 提供内容 |
| --- | --- | --- |
| 完整跟画 | guided | 成品参考、按实际操作拆解的步骤图、完整正文；适合新技法与需要详细帮助的练习 |
| 提示练习 | supported | 任务、关键中间示意、容易出错的操作和检查点，留出部分布局或配色决定 |
| 自主练习 | independent | 主题或观察任务、约束和检查点；原则上先自主构图，再按需展示示意或成品，避免预先替代构思 |

guided是首次练习的默认帮助程度；随着能力稳定逐渐转向supported和independent，想尝试自主或需要更多帮助时均可调整，不要求先完成某个等级。

步骤数量由真实操作需要决定，不限制六步，也不为凑数拆开同一个动作。每步写清新增内容、所用工具与色号、留白位置和关键检查点。同构图连续递进，干燥等待、覆盖顺序等关键操作不能跳过。复杂画分成多页或多个练习单元，禁止把所有步骤挤在一张难以辨认的图里。

每篇教案正文只维护一份，包含风格、等级、教学方式、工具色号、一个主要目标、先修能力、画面尺寸、估计总用时及可分次安排、对应步骤、常见问题、检查点与来源。成品图必须与声明的难度和工具能力匹配；若仅为高完成度展示，标明展示用途，不直接称为零基础跟画范例。

## 通用的新风格接入流程

1. 分析参考并确定独立视觉特点；题材、媒介和难度分别说明，不能只按画中物体命名风格。
2. 先制作原创候选，按请求数量展示并标出每幅预计等级、主要训练点和工具适配情况；候选数量不等于手绘进度或完整课程数。
3. 检查风格一致性、原创构图、难度真实性和已有工具可实现性。十幅展示可覆盖不同等级；只有成品图的高阶展示仍只是候选。
4. 确认收录后，参考[风格档案模板](../styles/STYLE-TEMPLATE.md)新增独立编号、档案和目录记录，保留已有风格，不自动切换默认。每种风格描述D1～D4的具体练习方式，只有完成的教程才标为可跟画。
5. 在风格目录的curriculum_paths声明该风格各阶段题库路径。新风格推荐curriculum/S编号/阶段.json；没有的课程暂不填，不创建空教案冒充完成。S001当前四阶段题库位于curriculum/S001/；旧curriculum/beginner.json保留为历史选题池。
6. 初始化该风格自己的学习进度，再从选定阶段准备教案。新教案记录style_id、stage、teaching_mode；作品编号全库唯一，风格编号与作品编号独立。

## 原创与工具适配

参考只用于提取色彩关系、线条、笔触、空间与光感等共性。重新设计主体组合、动作、道具关系、视角与布局；不能沿用参考中有辨识度的整套安排后只换色、镜像、裁切或增删小物。生成前比较构图方案，生成后对照所用参考与既有候选检查，明显重复的作品重做。系列内允许重复普通题材，但每幅必须有独立的画面安排和训练目的。

提示词与来源明确记录参考角色和原创设计；AI示意不冒充真实手绘。不得为充实风格库直接复制第三方原图；公开展示与照片使用遵循[公开规则](public-repository.md)。原创检查不能因采用AI生成而省略。

所有风格按实际工具设计画法，不照搬其他媒介的覆盖、混色或纹理效果。油性马克笔不能默认像丙烯笔一样浅盖深；白笔效果未验证前只作可选小高光，大块白形提前留纸。工具升级不作为晋级条件。

## 配色轮换与结构可读性

风格特征与固定色号分开。每次先从当前工具的36色中选配色，再写生成提示；控制单幅用色数量，同时回看最近3～5幅作品的主色、背景与冷暖，避免连续复用同一套配色或总以亮粉、深蓝作背景。允许根据主题重复主色，但应有明确画面理由，不用改一两个小配件伪装成新配色。保持风格一致不等于每幅颜色相同，也不要求一幅用完36色。

除常用亮色外，可按题材尝试2、11、24、25、31、37、41、58、63、65、67、69、71、135、143、172及WG灰色等已有色号。灰色可用于结构与衬托，不强迫所有色号在一组中平均出现。生成图的颜色只近似实物，教学最终以试色和明确色号为准。

每幅计划记录主色、背景色与辅助色的分工，批量生成时先检查整组配色差异，再生成。参考配色可按工具允许的色号组合：41／25／37／92，69／65／135／WG3，11／58／82／WG1，63／24／67／95；这些是可选方向，不成为新的固定模板。默认保留旧图；明确要求改配色时保存新版并同步当前图、配色与展示。已有完整教案若改色，还须同步步骤图和正文，不能只换成品。

用色统计按单幅列出的计划色号计算，黑色勾线与留纸白通常不占配色数量；黑色大块主体可列120。另检查背景、主体、点缀的面积角色，优先轮换承担大片填色的常用笔，并可用留纸白减少无关背景耗墨。出现次数不是实际耗墨，未测量墨量时不承诺36支同时用完，也不为凑齐色号硬用132。S001当前方案与修订前后统计见[配色计划](../styles/previews/S001-2026-11-01/palette-plan-v4.md)。

即使采用扁平色块，物体也应可识别、可解释：伞面需有穹顶、弧向与合理伞杆连接；口袋需有服装上下文、开口与缝合边；容器需有内外口沿；桌面应有一致的面与落地关系。优先用轮廓、前后遮挡、薄边和少量平涂暗面说明厚度与转折，不强加写实渐变。修订后同时检查动作接触、支撑和物件位置，必要时调整布局，而非只叠阴影掩盖结构错误。

## 维护命令与数据边界

```sh
# 显示所选风格的独立阶段、真实完成计数与待练教案
python3 scripts/drawing_diary.py status --style S001
# 只恢复该风格当前阶段的未完成作品；没有时从对应题库建草稿
python3 scripts/drawing_diary.py next --style S001
# 明确换题，保留旧作的未完成状态
python3 scripts/drawing_diary.py next --style S001 --new
# 根据实际练习复盘；以下为操作示例，不应未经评估直接执行
python3 scripts/drawing_diary.py review --style S001 --decision practice --evidence '主要形状已稳定，需要补两幅边界控制练习'
```

review的advance只改变所选风格的下一学习阶段，不把尚未完成的旧作标为完成，也不生成未来课程。若下一级暂无题库，说明需要备课。程序负责过滤、计数和保存评估；能力判断由实际反馈支持。
