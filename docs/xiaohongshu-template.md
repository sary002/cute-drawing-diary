# 可选分享模板

**只在用户想分享时使用。初学日常没有发布任务，也不要求任何过程照片。**

定位仍是“每天画点可爱的”，但内容随真实积累，不要求每天更新。先有学习体验，再选方便的形式。

| 形式 | 最少素材 | 可以写什么 |
| --- | --- | --- |
| 单张成品 | 一张本人已完成作品照片 | 编号、动物名、实际使用的色号 |
| 阶段合集 | 一张几幅画的合照，或几张成品照 | 这一阶段画了什么、发现的一点变化（有感受再写） |
| 跟学资料 | 原有教程和明确标注来源的教学示意 | 步骤、色号、留白提示；不称为用户绘画过程实拍 |

没有过程图不补拍；没有精确用时不写“20分钟画完”；没有实拍不把AI图冒充自己的手绘作品。需要AI辅助说明时按真实使用情况写，发布时核对平台当前声明要求。

## 最简成品稿

标题：初级001｜我的第一只马克笔小鸡

正文：
> 从这只圆滚滚小鸡开始，慢慢学画🐥
> Touchmark学生36色：37身体、24嘴和脚、9腮红。
> 纸张：16.5×16.5cm马克笔纸。
> [有感受才加一句，没有就省略。]
> [按实际情况说明练习参考与AI辅助来源。]

成品照本身即可构成内容，不强制加色卡页、过程页或复盘表。想统一外观时可以用3:4竖版；不要为了套版式重拍，保留画作比例即可。

## 合集稿

标题：刚开始学马克笔｜先攒了几只可爱小动物

配一张合照或几张成品图，正文列作品名称和本阶段练习目标。没有连续每天画，也不用写连续打卡；可以按作品编号逐步积累。

平台数据仅在用户想研究时再记录，不要求在发布后24小时、7天回访。教程版多页排版和视频拍摄等，等用户觉得画画顺手并明确想尝试时再讨论。
