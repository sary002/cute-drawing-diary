# 先选风格，再逐级学习

从[风格库](../styles/README.md)选择想学的画面风格，再沿D1基础大形、D2专项控制、D3综合组织、D4自主创作学习。各风格独立保存阶段与进度，共用[多风格学习规则](learning-system.md)；无需先完成另一种风格。

## 每次怎么练

1. 确认所选风格，恢复该风格当前阶段的未完成练习，或明确换题。
2. 围绕一个主要目标试笔，再按教案完成小作品。入门可用16.5厘米方本，画约8～10厘米；复杂画可放大或分次完成。
3. 检查当天重点。每个风格、每个阶段首次实际完成7幅后复盘，按能力进阶；需要巩固时补约2～3幅再看。

完整跟画、提示练习和自主练习可分别选择。步骤按操作需要安排，不限六步；复杂作品可分多页、多次练习。单次时间预算与整幅预计用时分别说明，计划用时不登记为实际用时。

## 工具与记录

按[工具档案](../config/tools/touchmark-student-36-v2.json)和当天教案选色，针管笔兼容性未知时先上色、干透后勾线。白笔未实测前只作可选小高光，大块白形仍留纸白。进阶不以购买新工具为前提。

画的时候不必拍过程。确认实际完成后再记录，日期、照片、用时和复盘均可省略；照片也可日后集中补充。分享使用真实成品，AI示意标明来源。

## 开始下一次练习

可以说：“用S001风格，继续我当前阶段的练习，给我详细步骤。”也可以指定“今天用提示练习”或“给我一个自主创作任务”。临时换风格不改默认值，并恢复该风格自己的进度。
