# 每天一幅小画，学一个基础点

每天约20分钟，从[每日一练总目录](../lessons/README.md)选一幅。可以重复同一幅，或分两次完成。

## 练习顺序

1. **基础小练习，约3分钟**：在废纸上试当天用到的形状和颜色，例如小鸡的圆胖轮廓、小三角嘴和水滴形翅膀。
2. **画小作品，约15分钟**：跟随当日教案起形、勾线和上色。16.5厘米方本的主体先画约8～10厘米，四周留白。
3. **检查一个重点，约2分钟**：只看当天的基础点，例如大形是否圆胖、颜色是否涂在合适区域，不必反复修到纸面变脏。

分钟数按实际进度调整。针管笔先测试是否耐酒精，晕染或兼容性未知时，先上色、干透后勾线。

## 记录与分享

画的时候不必拍过程。完成状态、成品照片和用时可按需记录，照片也可日后集中补充。分享时使用真实成品，AI示意保留来源标注；私人笔记留在本地。

## 阶段与工具

入门先练基本形、轮廓、平涂和纸白留白。积累几幅后再回看具体困难，逐步增加表情、姿势和小场景。阶段依据实际能力与舒适度调整，36色也能继续进阶。

## 开始下一次练习

可以直接说：“用 daily-cute-drawing 技能，开始今天的每日一画，按小鸡版式给我成品参考和六步图。”也可加主题，例如“今天想画湖边小山丘”。完整教案默认包含成品参考、竖版两列六步图、纸笔色号和一个基础点。

继续未完成练习可说“继续上次那幅”；换题可说“先保留上次的未完成状态，今天换一幅”。画完后说“这幅画完了”再登记，日期、用时、照片和复盘均可省略。
