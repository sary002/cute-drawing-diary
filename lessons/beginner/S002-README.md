这七课是S002的D1主线，S002-001～004保留为先前展示，不替换或混算。每课一个主要目标，不要求先学S001。每次约25～40分钟，可分次。先大形、后少量笔触；不把高细节展示图当作入门要求。

前两课建立大形与留白，第3～4课换植物题材迁移，第5～6课巩固笔触方向与简单明暗，第7课回看组合。所有图片是AI教学示意，实际完成仍为0幅。完整跟画不限制必须四步，当前四环节足以覆盖这些简化画面。

## 工具与阶段回看

16.5厘米方形马克笔纸、铅笔、橡皮与Touchmark学生36色油性马克笔；每幅3～5色，图像色彩非精确实笔色值，同纸试色优先。白形留纸白；不依赖白色高光笔或132覆盖。需要局部线条时先上色，干后勾线。

实际画完后再记录；七幅后复盘大形定位、主要色块、简单遮挡与留白。能力未稳可补2～3幅，数量达到不自动晋级。[D2～D4各7课详细正文与相应帮助图](../../styles/previews/S002-28-2026-11-02/README.md)已备齐，实际阶段仍按独立练习与复盘推进。
