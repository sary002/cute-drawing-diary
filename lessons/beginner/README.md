# 入门版练习｜36色马克笔画可爱小画

[每日一练总目录](../README.md) · [返回首页](../../README.md)

从圆、椭圆、三角形组合小动物，每次学一个基础点，练清楚轮廓和少色平涂。可直接打开[001 圆滚滚小鸡](001-chick.md)跟画。

也可选择[002 湖边小山丘](002-lakeside-hills.md)，用少量大形状练前后遮挡，约25分钟；仍沿用入门纸笔与2～5色平涂。

## 工具

| 工具 | 规格 | 用法 |
| --- | --- | --- |
| 马克笔专用纸 | 16.5×16.5厘米 | 主体约8～10厘米，居中留白，纸下垫废纸 |
| 铅笔 | 普通铅笔 | 轻画轮廓和定位线 |
| 油性马克笔 | Touchmark学生36色 | 每幅通常2～5色，色号在当日教案中标明 |
| 针管笔 | 0.5mm | 主轮廓、五官和小面积填黑 |
| 针管笔 | 0.15mm | 小嘴、脚趾等细节，可按手感选用 |
| 针管笔 | 1.0mm | 较粗轮廓时选用，小鸡这幅不用 |
| 粗勾线笔 | 粗细以实物为准 | 需要更粗轮廓时选用，小鸡这幅不用 |

完整色号见[36色工具档案](../../config/tools/touchmark-student-36-v1.json)。色号对应本套装，其他品牌先试色并选接近颜色，不必购买同款。

## 先试笔，再开始

- 针管笔线干后刷一笔马克笔；黑线晕染或兼容性未知时，先用浅铅笔定位、上色，颜色干透后再勾线。
- 用废纸试色，确认笔头和纸张表现。高光留纸白，不把132号当不透明白笔或无色混色笔。
- 每次约20～30分钟：先试色与练当天基础，再跟画，最后检查一个重点；以当日教案的计划时间为准，可以重复或分次完成。
