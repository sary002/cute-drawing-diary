# 入门版练习｜36色马克笔画可爱小动物

[每日一练总目录](../README.md) · [返回项目首页](../../README.md)

适合刚开始画画、每天想花约20分钟完成一幅简单小画的人。从圆、椭圆、三角形组合小动物，每次学一个基础点，先练清楚轮廓和少色平涂。

**直接从[001 圆滚滚小鸡](001-chick.md)开始。** 每幅教案是一篇完整文档，参考图、当天纸笔、色号、起形、勾线、上色和检查点都在同一页，在GitHub打开即可跟画。

## 本阶段用哪些工具

这是当前实际拥有的入门工具配置，档案版本为Touchmark学生36色v1。无需一次用齐；每篇教案会单独列出当天真正需要的几支笔。

| 工具 | 当前规格 | 入门怎么用 |
| --- | --- | --- |
| 马克笔专用纸 | 16.5×16.5厘米 | 动物先画约8～10厘米，居中留白；纸下垫废纸 |
| 铅笔 | 已有铅笔 | 轻起轮廓和定位线，避免画得太重 |
| 油性马克笔 | Touchmark学生36色 | 每幅通常选2～5色，先平涂；准确色号在当日教案中标明 |
| 针管笔 | 0.5mm | 主要轮廓、五官和小面积填黑 |
| 针管笔 | 0.15mm | 小嘴、脚趾等细节，按控制感选用 |
| 针管笔 | 1.0mm | 已有备用工具，当前第一幅不用 |
| 粗勾线笔 | 已有，粗细待实测 | 需要较粗轮廓时再用，当前第一幅不用 |

这套笔的完整色号见[36色工具档案](../../config/tools/touchmark-student-36-v1.json)。色号按此套装记录，跨品牌或不同套装先对照实物试色；其他读者可用接近的颜色练习，不必为跟画购买同款。

第一次用纸笔前，在废纸上试一下：

- 针管笔线干后刷一笔马克笔；黑线晕染或尚未确认兼容性时，先用浅铅笔定位、上色，颜色干透后再勾线。
- 马克笔先画小色块，确认实际颜色和纸张表现；笔头形状尚未确认，不要求特定笔头。
- 眼睛高光等亮部留纸白；132号的覆盖能力未确认，不把它当不透明白笔或无色混色笔。

## 怎样完成每天的一幅

参考节奏是**3分钟基础小练习＋15分钟画小动物＋2分钟检查**，可按实际进度调整。基础小练习可以画在废纸上；画本只留当天的小作品。第一次慢一些、重复同一幅或分两次完成都可以。

画的时候专心画，不要求拍过程。完成后可以只说“画完了”；照片、实际用时和感受可省略，以后想整理时再集中拍成品。

## 后续选题规划

小海豹（椭圆组合与纸白）→ 小兔（长耳朵的大小和间距）→ 小熊（大圆与小圆）→ 小企鹅（深色小面积控制）→ 小青蛙（左右呼应）→ 小猫（圆形与三角形）。这些是选题规划，完整教程准备好后才加入上方目录，顺序可以按学习情况调整。

入门阶段先练“能用基本形画出来、轮廓清楚、颜色涂在合适区域”。进阶时会另设学习目录，36色仍可继续使用；新增工具另记版本，旧教案保留当时的纸笔与色号。
