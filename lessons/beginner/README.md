## 先试笔，再开始

- 针管笔线干后刷一笔马克笔；黑线晕染或兼容性未知时，先用浅铅笔定位、上色，颜色干透后再勾线。
- 用废纸试色，确认笔头和纸张表现。大块白色仍留纸白，不把132号当不透明白笔或无色混色笔。
- 两支新增白笔先在废纸上试：涂一块当天的深色马克笔，完全干透后分别点白点、画短线，等白色干透后观察遮盖、泛色与附着。确认效果后再给画面加少量小高光，测试前不把白笔当大面积修正工具。
- 每次约20～30分钟：先试色与练当天基础，再跟画，最后检查一个重点；以当日教案的计划时间为准，可以重复或分次完成。
