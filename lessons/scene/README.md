[全部教案](../README.md) · [纸笔与试色](../beginner/README.md) · [学习规则](../../docs/learning-system.md)

已能控制曲线、表情、线条与简单遮挡；先完成D2复盘，或有相同能力。

同用16.5厘米方形马克笔纸、轻铅笔、Touchmark学生36色与针管笔。先试色，先上色、干透后勾线；纸白在起稿时规划，132不作覆盖白笔。

单幅最多8色，按当课计划分次完成。阶段进阶以真实作品能力复盘为准；生成或打开教程不计画完。

## 本阶段怎么练

每课先做废纸专项或两版小构图，再正式起稿。颜色数量随阶段增加，但不靠堆细节升级；优先检查主次、接触、支撑和留白。

完成7幅后可继续同级加练2～3幅；掌握后再依据真实反馈进入下一阶段。D4可持续续创，不设默认D5。
